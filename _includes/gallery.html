{% comment %} Reusable image gallery as a Bootstrap carousel. Reads all images from a folder automatically (sorted alphabetically by file name) and renders them as a slider with arrows and indicators. Usage: {% include gallery.html folder="assets/img/highlights/member-poster-gallery" ratio="2/3" %} parameters: folder (required) Path to the image folder, relative to the site root, with or without leading/trailing slash. ratio (optional) CSS aspect-ratio value matching the images in this gallery, e.g. "3/2" for landscape photos or "2/3" for portrait posters. Defaults to "16/9". All images in one gallery call are assumed to share the same ratio (crops to fit via object-fit: cover if a particular image doesn't match exactly). id (optional) Custom DOM id for the carousel. Defaults to a value derived from the folder name. Set this if you use several galleries on the same page.
